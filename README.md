# EduPro CRM: Ultimate Enterprise Edition

A high-performance, responsive, and lightweight CRM web application designed for lead management, call centers, admissions tracking, follow-ups, and sales analytics.

---

## 🌟 Key Features

1. **Dashboard & Executive Analytics**:
   - Real-time KPI metrics (Total Leads, Enrolled Students, Total Revenue, Follow-ups Due).
   - Monthly and quarterly revenue progress indicators.
   - Lead source and course breakdown analytics.

2. **Call Center Pipeline**:
   - Comprehensive lead pipeline with 1-click status transitions (Cold, Warm, Hot, Enrolled, Closed).
   - WhatsApp 1-click direct chat launcher.
   - Individual student profile drawer with full payment and remark histories.
   - 1-click lead deletion with instant persistence.

3. **Follow-Up Management**:
   - Filter follow-ups by Today, Overdue, Upcoming, or Completed.
   - Reschedule follow-ups with customizable date/time picker.

4. **Kanban Visual Board**:
   - Drag-and-drop lead stage management across Cold, Warm, Hot, and Enrolled columns.

5. **Student Admissions & Payments**:
   - Track Total Fee, Paid Amount, Due Balance, and Due Dates.
   - Printable money receipts / invoices with zero-latency preview.

6. **Cloud & Local Data Persistence**:
   - Automatic local storage synchronization across reloads (`localStorage`).
   - Bulk CSV import/export capabilities with pre-formatted templates.
   - GitHub / Cloud sync capabilities.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser:
```bash
# Direct browser opening
start index.html

# Or run the built-in lightweight local server
node server.js
```
The CRM server runs on `http://localhost:3000`.
